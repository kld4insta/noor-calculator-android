# نور | Noor Calculator

آلة حاسبة أندرويد بسيطة بواجهة عربية داكنة، وعمليات الجمع والطرح والضرب والقسمة والنسبة المئوية وتغيير الإشارة.

## البناء والتثبيت

افتح مجلد `NoorCalc` في Android Studio، وانتظر مزامنة Gradle، ثم اختر **Build > Build APK(s)**. يدعم المشروع Android 6.0 (API 23) فما فوق ويستهدف Android 14 (API 34).

يمكن البناء من الطرفية بعد تثبيت Android SDK وGradle:

```bash
gradle assembleDebug
```

ينتج ملف التثبيت في `app/build/outputs/apk/debug/app-debug.apk`.
